列车--

首末班与发车间隔来自公开运行图；区间运行时分按线网图推算。快车按公开时刻表尽量还原，但增停、临时调整仍可能不符。末班后、临时加开、晚点等情况不会反映。

这是什么

把几个广州地铁相关开源项目合在一起：用公开的首末班、发车间隔、区间运行时分和线路几何，按运行图推演每一列车此刻大概在哪，并算出每个站下一班还有多久。

为什么不是实时

广州地铁没有公开的车辆位置或 GTFS-RT 接口。官方仅在微信小程序里试点过“计划到站”，接口也已封禁。所以这里只能做到“运行图推演”，误差主要来自临时调度、加开、越行和晚点。

位置怎么算

每一段先按线路几何算出站间距离，再按计划运行时分生成一条速度曲线：出站加速、区间中段最快、进站减速，位置由这条曲线推进。广州地铁没有公开的实时速度，所以 tooltip 里的 km/h 也是推算值，不是实测速度；长区间按 160 km/h 封顶。

首末班前后为什么还有车

首班从线路两端的终点站发出，到你选的站还要跑一段。所以站台首班写着 06:18，不代表 06:18 才有车；06:10 地图上已经能看到 06:00 发出的车在区间里。末班也一样：本站末班过后，线上仍有车在跑完区间。

列车会停站吗

会。中间站按 20–25 秒停站处理，起点站待发约 1 分 36 秒；停站时列车固定在站上，点开 tooltip 会显示“停站中 · 约 N 秒后发车”或“起点站停站中”；本站倒计时在停站期间显示“已到站”。快车只在停靠站停，跳停站直接通过。

实际校正怎么用

看站台屏“往 X 方向 还有 N 分钟”时，在右侧“实际校正”里选同一方向，填 N，点“重算”。程序把这班车的模型到站时间对齐到 N，并把本线该方向今天这班及之后的班次整体平移；该站倒计时从这班开始，到站早于这班的同方向列车会从地图上隐去，发车早但到站晚的慢车仍保留。填 0 表示已经到站。没开共享时只影响本机当前线路的今天，换线或第二天自动失效；开了共享会同步给其他访客。它是一次观测修正，不会变成实时定位，也不能还原区间里的逐段晚点。

共享校正怎么同步

如果配置了 Cloudflare Worker 共享服务，点“重算”后会把“模型到站时间”和“站台屏实际分钟”的差值提交到服务端；服务端按同一条线、同一方向、最近 45 分钟内的报告取中位数，其他访客打开页面会自动拉到这个平移量。共享服务只保存线路、方向、站点编号、时间差和匿名 IP 哈希，不保存原始 IP；同一 IP 一分钟最多提交 3 条。没配置共享服务时，校正只写本机 localStorage，别人看不到。

快车怎么处理

18、14、21 号线按公开快车时刻表单独生成班次：橙色方块“快”是快车，只在停靠站进入倒计时，跳停站不显示。14 号线用 2026 年 3 月起增停竹料的 13 站方案；21 号线快车为天河公园短交路；18 号线时刻来自公开整理，工作日与周末暂按同一套。

箭头怎么看

每个列车标记前的小三角指向列车当前行进方向，不是线路图的固定朝向；拖动或缩放地图时箭头会跟着转。
